## 🔧 单个优化说明

### 1. Query 压缩 ⭐ 简单

**修改位置**: `main.py` 中 `--num_queries` 参数

```python
# 默认
--num_queries 300

# 改为以下任一
--num_queries 200  # -5% FLOPs, -0.1 mAP
--num_queries 150  # -25% FLOPs, -0.5 mAP
--num_queries 100  # -60% FLOPs, -1.5 mAP
```

**影响分析**:
- 📊 线性关系: FLOPs ∝ 1/num_queries (在 Decoder 部分)
- ⚡ 延迟影响: 主要在后处理阶段
- 🎯 精度影响: 对小目标检测更敏感

---

**影响分析**:

- 🎯 精度影响: 减少细节处理能力

**组合优化**:
```python

```

### 5. 注意力头数减少 ⭐⭐ 中等

**修改位置**: `main.py` 中 `--nheads` 参数

```python

# 改为

```

**约束条件**:
- ⚠️ `hidden_dim` 必须能被 `nheads` 整除
- 默认: 256 / 8 = 32, 256 / 4 = 64 ✓

```python

```

### 7. 知识蒸馏 ⭐⭐⭐ 复杂

**原理**: 使用大模型 (Teacher) 教小模型 (Student)

**Teacher 配置** (保持原始):
```python
# Teacher: 原始 Deformable-DETR
--backbone resnet50
--dec_layers 6
--num_queries 300
```

**Student 配置** (轻量化):
```python
# Student: 轻量化模型
--backbone mobilenetv3_large
--dec_layers 3
--num_queries 100
```

**蒸馏损失**:
```python
# 总损失 = 任务损失 + 蒸馏损失
Loss = L_task + α_cls * L_cls_distill + α_bbox * L_bbox_distill

# 其中
L_cls_distill = KL(softmax(p_s/T), softmax(p_t/T))
L_bbox_distill = MSE(bbox_s, bbox_t)
```

**训练流程**:
1. 预训练 Teacher 模型 (获得 checkpoint)
2. 加载 Teacher 权重
3. 初始化 Student 模型
4. 联合训练: Teacher frozen, Student 训练
5. 基准测试对比

## ⚠️ 常见问题

### Q: 为什么轻量化后反而更慢？
**A**: 可能原因：
- 内存访问模式改变，缓存命中率下降
- 不同硬件对不同操作的优化差异
- Python 循环开销相对增大（模型小时）
- **解决**: 在目标硬件上重新基准测试

### Q: mAP 下降多少是可接受的？
**A**: 
- 通常: 1-2 mAP 点可接受
- 实际应用: 根据业务需求
- 知识蒸馏: 可恢复 50-80% 的精度损失

### Q: 可以一次改所有参数吗？
**A**: 
- ❌ 不建议，难以定位问题
- ✅ 建议逐个优化，记录每一步的影响
- ✅ 使用消融研究理解组件交互

### Q: 需要重新训练吗？
**A**:
- Query/采样点/头数: ⚠️ 建议 fine-tune (10-20 epochs)
- Backbone 替换: ⚠️ 必须重新训练 (50+ epochs)
- 知识蒸馏: ✅ 必须重新训练
