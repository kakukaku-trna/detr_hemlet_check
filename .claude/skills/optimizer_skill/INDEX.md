## 📋 推荐阅读顺序

### 首次使用 (30-60 分钟)

```
1. 快速参考.md (15 min)
   ↓ 了解有哪些优化选项
2. README.md 简读 (20 min)
   ↓ 理解各方向的优先级和收益
3. 选择一个方案运行 (15 min)
   ↓ 验证框架是否适用于你的设置
```

### 系统化优化 (1-2 周)

```
1. 使用指南.md (20 min)
   ↓ 理解完整的工作流
2. prompts/analyze.md (30 min)
   ↓ 分析你的模型
3. 选定优化方向 (1 天)
   ↓ 基于分析结果做决策
4. prompts/optimize.md (1-2 天)
   ↓ 实施代码修改
5. prompts/benchmark.md (1-2 天)
   ↓ 测试性能和精度
6. templates/experiment.md (1 天)
   ↓ 记录和分析结果
```

### 深度研究 (2-4 周)

```
1. README.md 完整阅读 (1 小时)
2. 多轮优化迭代 (1-2 周)
3. templates/ablation.md (1 周)
   ↓ 做消融研究
4. 部署优化 (几天)
   ↓ ONNX/TensorRT
```
